# Lacunas do PRODUTO.md

O que o prodx não pôde determinar a partir da descrição. Em modo autônomo cada uma
virou premissa provisória em `docs/projeto/PREMISSAS.md` e pendência `decisao_humana`
no `docs/projeto/RECURSAO.md`.

| # | Lacuna | Premissa que a cobre | Quem responde |
|---|--------|----------------------|---------------|
| 1 | O sistema é para uma empresa usar (instalação própria) ou para vender contas a terceiros? | PR-02 | dono do projeto |
| 2 | Qual o nome do produto? | PR-03 | dono do projeto |
| 3 | Há volume esperado de mensagens e de base de conhecimento? | PR-04, PR-05 | dono do projeto |
| 4 | Onde vai rodar em produção (o script embutido precisa de URL pública HTTPS)? | PR-24 | dono do projeto |
